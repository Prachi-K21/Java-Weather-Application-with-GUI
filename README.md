Pixel Weather App is a retro-style weather application with a fully pixelated interface. It provides real-time weather updates with a fun, interactive design.

Features ✨

Retro pixel-themed GUI for a nostalgic look.

Real-time weather data: temperature, humidity, wind speed, and conditions.

Search any city with instant suggestions.

Unique pixel graphics for each weather type (sunny, rainy, smoky, etc.).

Lightweight and user-friendly interface.

Installation 💻

Clone the repository:

git clone <repository_url>


Open the project in your favorite IDE (like Eclipse or IntelliJ for Java).

Make sure you have the required libraries:

org.json

javax.swing and java.awt (standard Java libraries)

Run Main.java.

Usage 🚀

Launch the app.

Type the city name in the search bar.

Select from suggestions to view the weather.

See weather displayed with pixel graphics for fun visualization.

Dependencies 📦

Java 8 or higher.

JSON parsing library (org.json).

Internet connection for fetching live weather data.

Future Improvements 🔧
